# doxygen-awesome-css

Theme of the documentation generated by Doxygen (see `cmake/EvoCombDoc.cmake` and
`doc/Doxyfile.common.in`).

- Source: https://github.com/jothepro/doxygen-awesome-css
- Version: v2.5.0
- License: MIT (see `LICENSE`)

Only the files used by EvoComb are kept: the "sidebar-only" variant with the dark
mode toggle, the copy button of the code fragments, the links to the
paragraphs and the interactive table of contents.
